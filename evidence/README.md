# หลักฐานการทดสอบ

- `api-test-results.json` — ผลคำขอจริงจากชุดทดสอบ API 15 กรณี รวม status code และ response
- `api-test-report.svg` — รายงานภาพที่สร้างจากผล JSON

`api-test-report.svg` เป็นรายงานที่สร้างจากข้อมูลทดสอบ ไม่ใช่ภาพหน้าจอของเบราว์เซอร์ ตามโจทย์ที่ต้องแนบภาพหน้าจอ ให้เปิดเซิร์ฟเวอร์ด้วย `npm start` แล้วไปที่ `http://127.0.0.1:8000/api-tests` กด “เริ่มทดสอบ API” และจับภาพหน้าจอหน้านี้ รวมถึงหน้าแรกที่แสดงสถานะฐานข้อมูลเชื่อมต่อแล้ว
